# System_Portal_GH

Portal de Sistemas y Reportes de Órdenes de Servicio (Sistema PUSH para cPanel).

## Descripción
Este sistema extrae información de órdenes de servicio localmente y publica los reportes de manera segura en cPanel mediante HTTPS (PUSH outbound).

## Despliegue en cPanel
Configurado con `.cpanel.yml` para despliegue automático en `public_html/sistemas`.
